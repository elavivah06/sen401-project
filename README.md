# Student Management System (SEN 401)

A modular Python project demonstrating Software Configuration Management,
maintenance tasks, status accounting, re-engineering, and migration.

## Project Structure
- `app.py` — main demo application
- `students.py` — student data + core functions
- `utils/helpers.py` — utility functions (highest/lowest score)
- `requirements.txt` — Python dependencies
- `README.md` — this file

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python app.py`
